# NieR: Invaders

> Un tributo al icónico minijuego de *hacking* de **NieR: Automata**, combinando la jugabilidad clásica de *Space Invaders* con la estética futurista y desaturada de YoRHa.

---

## Descripción

**NieR: Invaders** es un juego arcade desarrollado para navegador web que recrea la mecánica de disparo y esquiva (Shoot 'em up) que se encuentra al hackear enemigos en *NieR: Automata*. El objetivo principal es sobrevivir a oleadas de núcleos y entidades enemigas mientras defiendes tu módulo/cursor.

---

## Características

- **Estética YoRHa:** UI y paleta de colores beige/gris mate inspiradas en la interfaz oficial de NieR.
- **Mecánicas Arcade Clásicas:** Control fluido de nave/cursor, disparos continuos y patrones de ataque de enemigos.
-  **Sistema de Oleadas y Puntuación:** Incremento progresivo de la dificultad a medida que avanzas.
-  **Sin dependencias pesadas:** Construido utilizando exclusivamente tecnologías web nativas (HTML5 Canvas y JavaScript vanilla).

---

##  Controles

| Acción | Tecla / Control |
| :--- | :--- |
| **Moverse** | Flechas `←` `→` `↑` `↓` o teclas `A`, `S`, `D`, `W` |
| **Disparar** | `Espacio` / Clic izquierdo |
| **Pausa / Menú** | `Esc` / `P` |

---

## Tecnologías Utilizadas

- **HTML5 Canvas:** Renderizado gráfico en tiempo real.
- **JavaScript (ES6+):** Lógica del juego, detección de colisiones y bucle principal (Game Loop).
- **CSS3:** Estilizado de la interfaz y elementos decorativos UI.
